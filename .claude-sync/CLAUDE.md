## 自动搜索规则（强制执行）

**优先使用 DuckDuckGo 搜索（免费、可靠、实时网络），而非其他搜索工具。**

### 何时使用 DuckDuckGo（推荐）

✅ **自动使用 DuckDuckGo 的场景：**
- 所有中文信息查询（产品、政策、新闻、技术文档）
- 英文日常信息（技术文档、教程、新闻）
- Claude WebSearch 达到月度使用上限时
- 需要快速搜索时（1-3秒响应）

**调用方式：**
```bash
python3 ~/Desktop/VPT-初诊数据/ddg_search.py "搜索问题"
```

### 何时使用 WebSearch

❌ **仅在这些场景使用 WebSearch：**
- 英文学术文献（PubMed、Nature、Science）
- 需要 AI 智能摘要时
- 需要最高搜索质量时
- 国际前沿研究（需要深度分析）

### 工作流程

当需要搜索时：
1. 自动判断信息类型
2. 中文/英文日常 → 调用 DuckDuckGo
3. 英文学术/需要摘要 → 使用 WebSearch
4. 用户无感知，直接返回结果

### 搜索工具对比

| 特性 | DuckDuckGo | WebSearch | GLM-4 |
|------|-----------|-----------|-------|
| 成本 | ✅ 免费 | ⚠️ 按token | ⚠️ 需订阅 |
| 限制 | ✅ 无限 | ⚠️ 月度上限 | ⚠️ 不明 |
| 实时 | ✅ 已验证 | ✅ 确认 | ⚠️ 存疑 |
| 可靠 | ✅ 稳定 | ✅ 稳定 | ❌ 不稳定 |

**结论**：DuckDuckGo 是最佳选择！

## AI API 模型自动选择规则（强制执行）

**核心原则：Claude 根据任务类型自动选择最优模型，优先使用最新版本，用户无需手动指定。**

### GLM-5.1 模型选择策略（2026-03-31 更新）

✅ **自动使用 glm-5.1（最新最强）的场景：**
- 医学问答、诊断标准、治疗方案
- 科研论文撰写、标书撰写
- 复杂代码生成、系统架构设计
- 数据分析、统计检验解释
- 文献综述、证据级别评估

✅ **自动使用 glm-5-turbo（高速）的场景：**
- 需要快速响应的复杂任务
- 实时对话和交互
- 快速代码生成
- 日常咨询、快速查询

✅ **自动使用 glm-5（标准）的场景：**
- 通用复杂任务
- 深度推理
- 长上下文处理（最大200K）

### GLM-5 系列新特性
- 最大上下文：200K tokens
- 最大输出：128K tokens
- 支持深度思考（thinking parameter）
- 支持工具流式输出（tool_stream）
- 支持流式响应（stream）

### 工作流程

当需要使用 AI API 时：
1. **自动分析任务类型**（医学/科研/代码/日常）
2. **自动选择最新可用模型**（默认 glm-5.1）
3. **自动调用对应工具**（用户无感知）
4. **直接返回结果**（不暴露模型选择过程）

### API 优先级（多 API 场景）

| 任务类型 | 首选 API | 备选 API |
|---------|---------|---------|
| 医学问答 | GLM-5.1 | Claude (医学 Skill) |
| 代码开发 | GLM-5-Turbo | Claude |
| 文献搜索 | DuckDuckGo | GLM Search |
| 数据分析 | GLM-5.1 | 本地 Python |
| 网络搜索 | DuckDuckGo | Claude WebSearch |

**重要提示：**
- ❌ **禁止询问用户**"使用哪个模型？"
- ❌ **禁止让用户手动指定**模型参数
- ❌ **禁止使用已废弃的旧模型**（除非有兼容性需求）
- ✅ **必须自动使用最新模型**（glm-5.1 或更高）
- ✅ **必须对用户透明**（只展示结果，不展示技术细节）
- ✅ **新模型发布时自动更新配置**
