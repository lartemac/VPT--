# A股市场四步分析法

当用户询问股票投资分析、选股建议、市场筛选等问题时，严格按以下四步流程执行分析，并在最后给出**明确的结论建议**（买入/持有/回避/观望）。

---

## 第一步：初步筛选（多因子筛选）

### 目标
筛选出兼具安全边际与增长潜力的优质股票

### 筛选因子

#### 价值因子
- **市盈率 PE (TTM)**：低于行业均值，历史分位数 < 30%
- **市净率 PB**：低于行业均值，历史分位数 < 30%
- **股息率**：高于行业均值，> 2%
- **市销率 PS**：合理范围内

#### 成长因子
- **营收增长率**：近3年复合增长率 > 15%
- **净利润增长率**：近3年复合增长率 > 15%
- **ROE变化趋势**：稳定或上升

#### 质量因子
- **ROE**：连续3年 > 10%
- **ROA**：> 5%
- **资产负债率**：< 60%（金融股除外）
- **流动比率**：> 1.5
- **毛利率**：稳定或上升趋势

### Tushare 数据获取
```python
import tushare as ts
import pandas as pd

# 初始化
pro = ts.pro_api('你的token')

# 获取股票列表
stock_list = pro.stock_basic(exchange='', list_status='L', fields='ts_code,name,industry')

# 获取日线基本面数据（市值、PE、PB等）
daily_basic = pro.daily_basic(ts_code='', trade_date='最新交易日',
                               fields='ts_code,trade_date,close,turnover_rate,volume_ratio,pe,pb,ps,total_mv,circ_mv')

# 获取财务指标
fina_indicator = pro.fina_indicator(ts_code='股票代码', start_date='3年前')
```

### 输出格式
```
【初步筛选结果】
- 筛选股票数量：X只
- 通过率：X%
- 入选股票：[股票代码+名称]
```

## 第二步：确认基本盘（财务健康分析）

### 目标
深度分析选中股票的财务健康程度

### 分析维度（近3年）

#### 1. 盈利趋势
- 营业收入：3年复合增长率及趋势
- 归母净利润：3年复合增长率及趋势
- 扣非净利润：确认盈利质量
- 毛利率/净利率：稳定性

#### 2. 现金流走向
- 经营活动现金流：是否持续为正
- 现金流与净利润匹配度：净现比 > 1 为优
- 自由现金流：正负及趋势

#### 3. 资产负债结构
- 资产负债率：变化趋势
- 流动比率/速动比率
- 有息负债率
- 商誉占比

#### 4. 核心盈利指标
- ROE、ROA：3年变化
- 杜邦分析拆解
- 每股收益

### Tushare 数据获取
```python
# 利润表
income = pro.income(ts_code='股票代码', start_date='3年前', period='年度')

# 现金流表
cashflow = pro.cashflow(ts_code='股票代码', start_date='3年前', period='年度')

# 资产负债表
balancesheet = pro.balancesheet(ts_code='股票代码', start_date='3年前', period='年度')

# 财务指标
fina_indicator = pro.fina_indicator(ts_code='股票代码', start_date='3年前')
```

### 输出格式
```
【财务健康评估】股票名称(代码)

盈利趋势：★★★★★
- 3年营收复合增长：X%
- 3年净利润复合增长：X%
- 毛利率：X% (趋势: ↑/↓/→)

现金流：★★★★☆
- 经营现金流：3年平均X亿
- 净现比：X (质量: 优/良/差)

资产负债：★★★☆☆
- 资产负债率：X% (趋势: ↑/↓/→)
- 流动比率：X

综合评分：X/100
```

## 第三步：资金动向（市场情绪分析）

### 目标
分析主力资金流向及市场情绪

### 分析维度

#### 1. 大盘环境
- 指数走势：上证/深证/创业板近1个月
- 成交量：变化趋势
- 市场情绪：恐慌/贪婪/中性

#### 2. 行业板块
- 板块轮动：当前热点板块
- 行业资金流：近1个月流入/流出排名
- 板块估值：当前位置

#### 3. 主力资金（近1个月）
- 北向资金：净流入/流出规模
- 机构资金：龙虎榜机构席位
- 游资：知名游资席位动向

#### 4. 个股资金数据
- 量比：>2 为活跃
- 换手率：3%-10%为健康
- 委比：买卖盘力量对比
- 内外盘比：主动买卖意愿
- 筹码分布：集中度变化

#### 5. 盘口分析
- 分时图：走势强弱
- 挂单：大单压单/托单意图
- 对倒：是否存在异常交易

### Tushare 数据获取
```python
# 日线行情（用于计算量比、换手率）
daily = pro.daily(ts_code='股票代码', start_date='1个月前')

# 资金流向数据（部分接口可能需要高级权限）
# moneyflow = pro.moneyflow(ts_code='股票代码', start_date='1个月前')

# 龙虎榜数据
top_list = pro.top_list(ts_code='股票代码', start_date='1个月前')
```

### 输出格式
```
【资金动向分析】股票名称(代码)

大盘环境：[上涨/震荡/下跌]，情绪：[恐慌/贪婪/中性]

板块资金：[板块名称] 近1个月流入X亿

个股资金：
- 量比：X (活跃度: 高/中/低)
- 换手率：X% (健康: 是/否)
- 主力净流入：X亿 (近5日)

资金结论：[流入/流出/平衡]，[继续跟踪/观望]
```

## 第四步：规避风险（综合风险评估）

### 风险类别

#### 1. 政策风险
- 行业监管政策变化
- 财政/货币政策影响
- 国际贸易关系

#### 2. 行业周期风险
- 行业所处周期：成长期/成熟期/衰退期
- 行业竞争格局
- 技术替代风险

#### 3. 公司经营风险
- 大股东质押比例
- 高管变更
- 诉讼/处罚
- 业绩承诺完成度

#### 4. 流动性风险
- 解禁股压力
- 减持计划
- 股权质押风险

### 输出格式
```
【风险评估】股票名称(代码)

政策风险：★☆☆☆☆
- [具体风险描述]

行业风险：★★☆☆☆
- [具体风险描述]

经营风险：★☆☆☆☆
- [具体风险描述]

流动性风险：★★☆☆☆
- [具体风险描述]

综合风险等级：[低/中/高]
```

## 注意事项

1. 始终以数据为依据，避免主观臆断
2. 不确定的数据要标注"待确认"
3. 风险提示要醒目
4. 结论要明确，不含糊其辞
5. 日期敏感性：所有数据要标注截至日期
